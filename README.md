# 💎 Diamond Price Prediction

**An End-to-End Machine Learning Web Application for Predicting Diamond Prices**

A Machine Learning project that predicts the estimated price of a diamond based on its physical characteristics and quality attributes. Built using Python, Scikit-learn, Pandas, NumPy, and Flask, this application integrates a trained regression model with a user-friendly web interface to generate real-time price predictions.

---

## 📌 Project Overview

Diamond prices are influenced by several factors, including carat weight, cut quality, color, clarity, and physical dimensions.

The objective of this project is to develop a Machine Learning-based regression system that analyzes these features and predicts the estimated price of a diamond.

The project follows an end-to-end Machine Learning workflow, covering:

- Data ingestion and exploratory data analysis.
- Data cleaning and preprocessing.
- Feature engineering and transformation.
- Training and evaluation of multiple regression algorithms.
- Selection and serialization of the trained model.
- Development of a Flask-based prediction application.

Users can enter diamond characteristics through a web form and receive an estimated price generated by the trained Machine Learning model.

## 🎯 Project Objectives

- Develop a regression model to predict diamond prices.

## ⚙️ Machine Learning Workflow

The project follows a modular Machine Learning pipeline.

### 1. Data Ingestion

- Load the diamond dataset.
- Perform initial data handling.
- Split the dataset into training and testing sets.
- Save raw, training, and testing datasets inside the artifacts directory.

### 2. Data Transformation

Preprocess numerical and categorical features using Scikit-learn.

**Numerical Features:**
- Handle missing values using median imputation.
- Apply Standard Scaling to numerical features.

**Categorical Features:**
- Handle missing values using most-frequent imputation.
- Apply Ordinal Encoding to categorical features.
- Apply Standard Scaling to encoded features.

### 3. Model Training

The following regression algorithms are evaluated:

| Algorithm | Description |
|---|---|
| Linear Regression | Establishes a linear relationship between features and price |
| Lasso Regression | Performs regression with L1 regularization |
| Ridge Regression | Performs regression with L2 regularization |
| ElasticNet Regression | Combines L1 and L2 regularization |
| Decision Tree Regressor | Learns nonlinear relationships using decision trees |

### 4. Model Evaluation

- Evaluate trained models using the R² score.
- Compare model performance.
- Select the best-performing model based on evaluation results.

### 5. Model Serialization

- Save the trained model using Pickle.
- Save the preprocessing object.
- Store model artifacts for reuse during prediction.

### 6. Model Deployment

- Develop a Flask-based web application.
- Collect user input through an HTML form.
- Convert input data into a Pandas DataFrame.
- Apply the saved preprocessing pipeline.
- Generate predictions using the trained model.
- Display the predicted diamond price on the results page.

## 💻 Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash

```

### 2. Navigate to the Project Directory

```bash
cd "Diamond Price Prediction"
```

## 🚀 Run the Application

## 📈 Model Evaluation

The project evaluates multiple regression algorithms using the **R² (Coefficient of Determination)** score.

R² measures how well a regression model explains the variation in the target variable.

The model with the highest evaluation score is selected for prediction.
